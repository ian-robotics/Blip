# 开发与验证指南

## 环境与命令

- 浏览器需支持 ES Modules 和 `structuredClone`。
- Node.js 20+：运行内置测试和静态检查。
- Python 3：提供本地静态服务。
- npm：仅作为命令入口；没有第三方依赖，不需要安装包。

| 命令 | 用途 |
| --- | --- |
| `npm start` | 在 8000 端口启动静态服务 |
| `npm test` | 运行 Node 内置测试 |
| `npm run check` | JS 语法、模块路径、DOM ID 和 CSS 导入检查 |

静态检查不执行真实页面布局，不验证实际浏览器麦克风支持。

## 常见修改入口

| 需求 | 修改位置 |
| --- | --- |
| 修改颜色、字体和暗色主题 | `css/base.css` |
| 修改手机布局与任务卡片 | `css/components/phone.css` |
| 修改输入/升级弹层 | `css/components/overlays.css` |
| 修改宠物面板 | `css/components/pet.css` |
| 修改等级、XP、徽章文案 | `js/config/game.js` |
| 修改初始任务和演示进度 | `js/state/initial-state.js` |
| 修改成长、徽章判定与跨天规则 | `js/domain/progression.js` |
| 修改文本拆分与优先级识别 | `js/domain/parser.js` |
| 修改语音语言或错误处理 | `js/services/speech.js` |
| 修改状态保存方式 | `js/services/storage.js` |
| 增加持久状态操作 | `js/state/store.js` |
| 修改页面展示 | `index.html`、`js/ui/render.js` |

业务规则用普通数据表达，测试中不要依赖 DOM。UI 中插入用户提供的 HTML 文本时使用 `esc()`，纯文本使用 `textContent`。更改 DOM ID 后同步更新相关 UI 模块，运行 `npm run check`。

## 新增功能流程

1. 定义字段或配置；若影响持久数据，先确定兼容和迁移策略。
2. 在 domain 实现规则，添加能验证实际业务行为的测试。
3. 在 Store 添加动作，统一持久化和发出事件。
4. 在 UI 绑定交互；由入口连接需要的跨模块反馈。
5. 运行自动检查，再验证实际页面；更新对应文档。

初始化函数在启动时调用一次，避免重复绑定监听器。页面仍由单个 HTML 组成；没有路由、服务端接口或组件模板系统。

## 手工回归

使用本地服务访问页面，打开浏览器开发者工具，确认无加载错误后检查：

1. 初始 HUD、宠物像素图、任务和页签显示正常；切换 Today/Blip。
2. 完成第一项高优先级任务：XP 从 40 到 70，显示 LV2 和升级弹层；再次点击不增加 XP。
3. 删除任务、刷新页面，确认变更保留。
4. 打开输入面板；输入 `buy milk and eggs, email the TA, maybe clean my desk on Sunday`，确认 3 个草稿；切换优先级、移除一项、添加剩余项。
5. 在示例动画过程中提交手动输入、关闭后重开，确认旧动画不覆盖新结果。
6. 允许麦克风并说英文，点击 Done；再验证拒绝权限或无识别能力时的示例回退。
7. 完成当天任务后跳到明天，检查连续天数及未完成任务保留；没有完成任务时跳日应归零。
8. 升级反馈尚未出现时立即 Reset，确认没有旧升级弹层延迟出现。
9. 检查窄屏、系统暗色模式与减少动画偏好。
10. Reset 后刷新，确认恢复初始演示状态。测试 Reset 会清除当前进度，建议使用独立浏览器配置测试。

## 部署

将项目静态文件部署到支持 JavaScript MIME 类型的静态托管服务，保留目录和相对路径。页面没有构建产物，`index.html` 即入口。语音功能需结合目标浏览器在 localhost 或 HTTPS 环境中验证。开发用的 Python 服务用于本地调试。

## 故障定位

- 页面无交互：确认 URL 为 HTTP/HTTPS，查看 Console 中模块加载错误；检查服务器是否从项目根目录启动。
- 模块或样式 404：运行 `npm run check`，确认发布时目录完整。
- 进度消失：检查是否更换源或浏览器；检查存储是否被禁用，或数据格式是否不合法。
- 麦克风不工作：检查权限和浏览器能力；可以继续使用输入框。自动测试只验证适配器逻辑。
- 字体与截图不同：检查 Google Fonts 资源是否加载，离线时会回退到系统字体。
